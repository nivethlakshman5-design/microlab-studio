# MicroLab Studio design brief

- **Design read:** MicroLab Studio is a hands-on learning workspace for beginners and makers learning Arduino and ESP32 through small, confidence-building experiments; the tone is precise, optimistic, tactile, and approachable rather than gamer-neon or enterprise SaaS.
- **Concept spine:** The Circuit Expedition. A single continuous camera journey moves from a clean maker's bench into the details of a microcontroller, then the pin connections and finally a small working LED circuit. Every page section is a waypoint in that expedition.
- **Delivery tier:** cinema. A scroll-controlled, continuous film is the primary interaction, supported by purposeful section reveals and a responsive, keyboard-friendly application shell.
- **Locked palette:** cool lab paper `#F2F4F2`, ink `#172321`, muted slate `#61706D`, accent coral `#D74455`, board green `#28584B`. Coral is reserved for the single decisive accent; cool paper and graphite-green make the electronics feel real without falling into neon-dark-tech tropes.
- **Locked type:** Satoshi-like geometric grotesk for display, IBM Plex Mono for code, pin labels, and measurements. No serif.
- **Animation mode:** animated-website
- **Journey shape:** single-shot. One continuous camera move gives a coherent beginning-to-end discovery without fragile clip seams.
- **Journey:** 1. Bench / “Start with a spark.” Wide clean maker bench, microcontroller and LED components; 2. Board / “Meet your board.” Smooth push-in to the ESP32/Arduino form factor and readable physical detail; 3. Pins / “Connect the dots.” Slow macro travel over pins, jumper wires, breadboard rails; 4. Code / “Make logic visible.” A subtle rack-focus toward a small display and LED circuit, no rendered UI/text; 5. First light / “Build something real.” The LED comes on as the camera resolves into a composed close-up with breathing room for the final message.
- **World grammar:** one clean, cinematic tabletop laboratory; photorealistic physical electronics, satin aluminum, matte dark-green PCB, translucent breadboard, coral jumper-wire detail; soft upper-left daylight and restrained edge lighting; fixed exposure and white balance; no text, no logos, no screen lettering, no watermarks. Center-safe composition with open negative space on the left for copy.
- **Mobile framing:** focal board and LED remain in the center 60% of frame, copy stays in a narrow readable column, alternate lighter mobile encode and exact-frame poster.
- **Delivery budget:** desktop film <=32 MiB, mobile film <=16 MiB.
- **Section plan:** 1. Scroll-scrub cinematic journey; 2. editor workspace shown as a real interactive product canvas; 3. lesson path as editorial waypoint list; 4. circuit simulator as a contrasting split-workbench; 5. project gallery as an offset, image-led set; 6. closing start-building callout with oversized circuit numeral. Avoid consecutive sections using the same layout family.
- **Asset plan (delivered):** one generated electronics-scene crop animated into a continuous 16:9 slow camera-move clip; exact first-frame desktop/mobile posters and optimized desktop/mobile encodes; branded cover + OG image; favicon family and web manifest; a custom circuit monogram; four original vector project illustrations. All media is bundled as static site assets. No runtime image/video generation. The Higgsfield image-batch endpoint was unavailable on the connected plan, so the static art and cover were authored with the available image and local graphics tools.
- **CTA inventory:** hero “Open the lab” is a route-drawing text link; editor “Run sketch” is a physical switch-style control; lessons “Start lesson” is a numbered waypoint row; simulator “Test circuit” is a terminal-style command action; project “Open project” is a cropped specimen label; final “Build your first circuit” is an oversized typographic target. Each CTA owns its own style and behavior.
- **Previous-build anti-convergence ledger:** no earlier build in this project. Chosen identity axes: cool pristine lab palette, geometric grotesk + mono, left-negative-space continuous camera journey, A4 scroll-scrub, individually garment-specific circuit/waypoint CTAs, square-cut calibration-corner language.
- **Product behavior:** a browser-based Arduino/ESP32 learning studio with editable C++ sketches, board profiles, runnable starter examples, lessons/quizzes, a limited honest virtual circuit simulation, serial output, and local progress persistence. No physical device connection or actual hardware compile is claimed unless a supported integration exists. AI tutor must disclose if no provider is configured.
- **Quality gate:** typecheck; template adaptation check; mechanical SEO/accessibility/security/reduced-motion checks; confirm all referenced media exists; check desktop/mobile layout and meaningful interactions before deploy.
